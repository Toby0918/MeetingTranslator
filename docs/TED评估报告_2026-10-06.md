# MeetingTranslator 1.0.0：TED 对照评估

评估日期：2026-10-06。平台：Windows x64，Intel Core i7-13700K，CPU int8。机器可读数据见同目录 benchmark-v1.0.0.json；素材身份、视频 SHA-256 和重跑入口见 scripts/ted_sources.json 与 scripts/evaluate_ted.py。

## 结论与适用范围

本版完成五段真实 TED 音频的改进前后对照，合计约 41 分 20 秒。英语识别参考文本合计 6,631 个词，词错误总数从 503 降至 409，整体词错误率从 7.586% 降至 6.168%，错误数量相对减少 18.7%。这个结果只表示本组音频的英语识别改善，不能当成中文翻译准确率或真实会议准确率。

离线翻译修复了多句字幕只译首句、明确英文单词计数被变成汉字数量、少量习语误译及不可读输出的处理。但 AI 抽样评审没有支持“中文翻译全面提升”的结论：忠实度均分小幅上升，流畅度均分下降，一段演讲明显退步。本版适合作为可下载运行的初版工具；复杂上下文、人名、数字、否定和专业术语仍需核对。

模型权重没有训练或修改。本次优化是实际应用中的分段、句子准备、解码与错误处理；不是用少量 TED 训练出新的翻译模型。

## 方法

原始应用在修改前复制并记录散列作为基线。两版读取同一完整音轨，经同样的解码器转换为 16 kHz 单声道。逐个输入实际应用的分段器，再用 Whisper small.en、CPU int8、beam size 2 识别；随后调用实际离线翻译路径。官方字幕仅在生成结果后用于评估，未输入识别器或翻译器。

WER =（替换 + 插入 + 删除）/ 参考词数。对官方英语 VTT 和识别文本进行大小写、标点和舞台提示归一化。数字的书写与口述差异、声音练习和非言语内容仍可能造成计分差异，所以 WER 不是完美的人类标注指标。本次没有人工逐词标注所有音频。

比较过 beam size 5 与改进分段的组合，但开发集表现弱于保留 beam size 2 的方案，因此没有发布该识别参数变化。最终语音改进主要来自到达 12 秒上限时寻找最近短暂停顿，并保留下一段的尾部采样。半秒停顿触发及无合适停顿时的上限处理仍保留。

AI 增强翻译使用现有 DeepSeek 配置完成五段基线识别文本，共 266 个字幕请求，265 次成功、1 次超时。超时没有计为成功，也未用静默重试掩盖。云端仅收到识别文字和有限前文，音频在本机处理。AI 翻译用于辅助发现语义与上下文问题；不是严格的人类参考译文。

为隔离识别变化对翻译的影响，AI 评审使用相同的基线英语识别文本，比较旧离线译文与新离线译文。每段取 12 个覆盖全程的样本，Cutts 另纳入三个问题样本，共 63 对；后者使抽样偏向已知问题。A/B 标签交错隐藏版本，忠实度及流畅度各以 0–4 分计。评审看不到官方 TED 逐字稿。评审与增强翻译使用同一供应商，样本非随机，未用人类评级校准，可能存在偏差；这些评分仅用于诊断，不是翻译准确率认证或统计显著性结论。

| 演讲 | 参考词数 | 旧版错误数 / WER | 新版错误数 / WER |
| --- | ---: | ---: | ---: |
| Cutts | 480 | 4 / 0.833% | 7 / 1.458% |
| Treasure | 1,661 | 175 / 10.536% | 132 / 7.947% |
| Rosling | 3,158 | 293 / 9.278% | 247 / 7.821% |
| Sivers | 470 | 16 / 3.404% | 16 / 3.404% |
| Duckworth，独立验收 | 862 | 15 / 1.740% | 7 / 0.812% |
| 合计，加权 | 6,631 | 503 / 7.586% | 409 / 6.168% |

Cutts 略有退步，Sivers 不变，其余三段改善。整体结果不是每篇都更好。独立验收错误从 15 降至 7，是这篇音频的观察结果，样本量不足以估计总体改善幅度。

## 中文翻译诊断

| 演讲 | 对数 | 忠实度：旧 / 新 | 流畅度：旧 / 新 |
| --- | ---: | ---: | ---: |
| Cutts | 15 | 2.800 / 3.133 | 3.133 / 3.133 |
| Treasure | 12 | 2.583 / 2.833 | 2.833 / 2.917 |
| Rosling | 12 | 2.750 / 2.750 | 3.000 / 2.667 |
| Sivers | 12 | 2.417 / 2.167 | 2.417 / 2.167 |
| Duckworth，独立验收 | 12 | 2.750 / 2.750 | 2.750 / 2.750 |
| 合计，按对数加权 | 63 | 2.667 / 2.746 | 2.841 / 2.746 |

忠实度比较中 11 对改善、42 对持平、10 对下降。Sivers 的抽样结果下降；逐句处理能够保留原先被漏掉的后续句子，但也会暴露单句模型在片段上下文中的低质量输出。新方案不保证每句更自然。独立验收的翻译均分持平，不能宣称在未见主题上全面提升。

最终完整音频共生成 271 条字幕，其中 Treasure 有 1 条在两种本地解码后仍不可读，按失败处理并保留英文。其他四段未出现该类解码失败。“解码成功”只表示输出可读，不表示语义正确。离线模型仍会误译短语、代词、术语和不完整句。

实际模型复核支持的修复包括：多句字幕逐句翻译，保留后续否定和补充；把明确的 sleep deprivation 语境准备为 insufficient sleep，减少误作“失眠”；把 a ton of fun 准备为 a lot of fun，减少按质量单位直译；明确的英文 word count 保留“单词”单位，避免变成汉字计数。

数字后处理采用保守匹配。字节、字符、字母等单位不修改；同一句中相同数值对应不同单位时不猜测；无法安全理解的混合或复杂中文数值保持原样。回归测试覆盖“500 words 和 1024 bytes”、数字逐字写法、嵌套单位及“1万5千”等后缀误匹配问题。这些规则不是通用语义理解器。

## 可复现性与软件验证

自动测试共 53 项通过，覆盖输入设备、采集取消、分段尾部保留、停止行为、字幕导出、云端错误与密钥脱敏、便携模型定位和翻译回归。独立只读复查发现的问题均加入失败测试后修复，并重新通过全部测试。

scripts/evaluate_ted.py 默认只运行本地模型。需要显式 --download 才下载素材，并校验视频 SHA-256；默认只写统计。--save-captions 会把全文保存到个人本地缓存，应保留在 Git 忽略目录。--baseline 可复现旧分段与整段翻译路径。--limit-seconds 是冒烟测试，输出不报告完整演讲 WER。模型版本、计算平台及网络素材变化会影响重跑。

本地缓存保存逐段结果用于核查，但不公开全文。benchmark-v1.0.0.json 包含基线与最终源文件散列、逐篇错误分解、AI 抽样计数、可读性失败数和计时。最终语义处理修正后重新生成了所有离线译文；完整音频识别没有因纯翻译修正重复运行。elapsed_seconds 为完整音频运行当时的文件处理计时，mt_refreshed_seconds 为最终译文复核计时，二者不能混同，也不代表实时字幕延迟。

发布包另行验证完整 ZIP 解压、文件散列、包含中文和空格的运行路径、清除开发环境变量后启动、真实隐藏界面创建、实际模型加载、设备枚举以及真实 TED 短音频的本地识别翻译。最终细节见仓库 release-verification-v1.0.0.json；该证据应在完成实际包测试后填写。

## 尚未验证的边界

本次没有完成真实多人 Zoom/Teams 会议、远距离现场讲话或另一台物理电脑的完整验收。文件音频评估与当前机器的隔离解压测试证明的范围有限，不能替代这些使用场景。模型输入是英语，尚未提供多语种识别或中文到英语翻译。

便携版无需安装 Python 和首次下载模型，但 CPU、内存、磁盘、音频驱动、Windows 版本及安全软件仍会影响可用性。程序未商业签名，可能出现未知发布者提示。下载后应保留整个文件夹，并从私有仓库 Release 获取完整 ZIP 与 SHA256SUMS.txt。
