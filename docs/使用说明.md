# MeetingTranslator 1.0.0 使用说明

本软件将英语声音识别为文字，并显示简体中文翻译。下载 Windows x64 便携 ZIP 后完整解压，打开 MeetingTranslator 文件夹，双击 MeetingTranslator.exe。模型与运行环境已包含在包内；保留整个文件夹即可离线运行。源码开发者的旧启动脚本不属于便携版入口。

## 电脑会议声音

选择“电脑会议声音”，再选择会议软件实际使用的耳机或扬声器，点击“开始翻译”。程序读取该播放设备的声音。若无字幕，确认设备一致、会议正在播放声音，并查看程序音量条是否变化。

## 现场麦克风

选择“麦克风（现场英语）”和实际收音的麦克风，点击“开始翻译”。麦克风应靠近讲话者。线路或虚拟输入不一定能收到房间声音；检查静音、设备和 Windows 麦克风权限。程序不会更改系统隐私设置。

## 翻译模式与字幕

默认“本地翻译（免费）”，不需要网络或密钥。需要增强翻译时，先停止，选择 DeepSeek 模式，点击“设置 API 密钥”输入自己的密钥，再开始。输入的密钥只存于本次进程内存，关闭后清除。增强模式把识别文字与有限前文发送至 DeepSeek 官方接口，音频留在本机；需要网络与自己的 API 余额。

输入来源、设备和翻译模式在运行时锁定，先停止再切换。“悬浮字幕”打开置顶双语窗口。“导出记录”手动保存文字。正常运行不自动保存音频或字幕；关闭前导出需要保留的记录。等最后一句处理完再停止，停止会取消尚未完成的处理。

字幕按片段出现：约半秒静音触发处理；连续讲话通常最多约 12 秒分段。达到上限时优先寻找最近的短暂停顿，剩余声音进入下一段。界面处理时间不包括等待讲话停顿的时间。

## 问题处理与验证范围

增强模式失败会保留英文并提示错误。可停止后检查密钥、网络和余额，或手动改用本地模式。本地译文无法正常解码时同样保留英文并提示，不把不可读字符当成成功结果。

提示模型缺失时，重新完整解压 ZIP，并确认 models 和 _internal 文件夹在 EXE 旁边。可使用 README 中的自检方式生成诊断报告。软件未进行商业代码签名，只从该仓库 Release 下载并核对校验值。

本版通过完整 TED 文件评估及解压运行验证，但仍可能误译人名、数字、单位、否定与复杂长句。多人同时讲话、背景噪音、远距离收音和会议专业术语需要额外核对。TED 文件结果不能替代真实 Zoom、Teams 或现场多人会议验收。
